# llm-nai-toolbox

用 LLM 把一句中文需求翻译成 NovelAI 的结构化提示词，人确认后出图。

![状态](https://img.shields.io/badge/状态-0.9.2%20预发布-e0a458) ![平台](https://img.shields.io/badge/platform-Windows%20x64-555)

> **0.9.2 预发布（内部测试）。** 「一句话 → LLM 查标签并回填 → 出图」整条流程已经能用，界面和配置格式还可能调整。各版本改动见 [更新日志](CHANGELOG.md)。

---

## 它做什么

你在底部指令区说一句话，模型去本地标签库里查标签、挑词，然后把结果**按字段填进编辑器**——人数构图归 `count`、画师归 `artist`、外观归 `appearance`、场景归 `environment`，各归各位。你看一眼、改几处，点生成。

```
一句话需求 → LLM 多轮查标签 → 回填各字段与参数 → 你确认/微调 → NovelAI 出图
                                                ↑
                                      「回填后自动生成」开着就跳过这一步
```

**只做 NovelAI。** 不接 SD WebUI / Forge。

## 安装

从 [Releases](https://github.com/sadlywish/llm-nai-toolbox/releases) 下载，三选一：

| 文件 | 说明 |
|---|---|
| `llm-nai-toolbox-<版本>-setup.exe` | 安装版，可选安装目录，建桌面快捷方式 |
| `llm-nai-toolbox-<版本>-portable.exe` | 便携版，单个 exe，双击即用 |
| `llm-nai-toolbox-<版本>-win-x64.zip` | 压缩包，解压后运行 `llm-nai-toolbox.exe` |

- 安装包没有代码签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
- 标签库已经打在包里，不用另外下载。

## 第一次使用：必须填的设置

首次启动会直接打开「设置」标签。下面两组填好，点页面底部的「保存」，再切到「工作台」。

### 1. LLM API（必填，不填发不出指令）

| 设置项 | 怎么填 |
|---|---|
| 接口类型 | **Claude**：Anthropic 官方或兼容 `/v1/messages` 的中转。**OpenAI 兼容**：OpenAI、OpenRouter、DeepSeek 等提供 `/v1/chat/completions` 的服务 |
| API 地址 | **只填到 `/v1` 之前**，程序会自己拼上 `/v1/messages` 或 `/v1/chat/completions`。例：`https://api.anthropic.com`、`https://api.openai.com`、`https://openrouter.ai/api`。多写了 `/v1` 会变成 `/v1/v1/...` 请求失败 |
| API Key | 必填。保存后不再显示，框里只写「已保存（留空则不修改）」；要换 Key 就重新填 |
| 模型 | 模型名，例如 `claude-sonnet-5`。**模型必须支持工具调用**（tool use / function calling）——查标签、回填参数都靠它 |
| 最大输出 token、请求超时 | 默认即可 |

### 2. NovelAI（出图必填）

| 设置项 | 怎么填 |
|---|---|
| NovelAI Token | 在 NovelAI 网页版的账户设置里获取 Persistent API Token（`pst-` 开头）。没填点「生成」会提示「未配置 NovelAI Token」 |
| 保存目录 | 点「选择…」指定出图存哪。没设置点「生成」会提示「未设置图片保存目录」。图按日期分子目录存 |
| 接口地址 | 默认 `https://image.novelai.net`，一般不用改 |
| 像素上限 | LLM 回填时按「宽高比 + 像素上限」算宽高。预设 Normal（1024×1024）在 Opus 会员免费出图范围内；选 Large / Wallpaper 会消耗点数 |
| 其余（图片格式、超时、重试、任务间隔、历史保留天数、角色数上限） | 默认即可 |

### 3. 按需填写

| 设置项 | 说明 |
|---|---|
| Danbooru 用户名、API Key | 可不填，匿名也能用右侧 WIKI；填了翻页上限更高、限流更宽 |
| 网络 · 代理 | 留空跟随系统代理；也可以填 `http://127.0.0.1:7890`、`socks5://127.0.0.1:7890` 这样的地址。LLM、NovelAI、Danbooru 的请求都走这里 |
| 思维链 | 模型支持思考时可以打开。OpenAI 兼容接口要在「参数写法」里选对应的厂商写法（OpenAI / Gemini / xAI、OpenRouter、DeepSeek / 智谱 / Kimi、通义千问各不相同） |
| 提示词 | 系统提示词、质量词、负面词自带一份默认值，可以改；「恢复默认」拿回随包的版本 |

设置页的小规则：改了没保存就切去别的标签，草稿留着，「设置」标签上挂一个黄点；底部「撤销修改」回到上次保存的值。质量词、负面词留空时框会黄色高亮提醒（不影响保存）。

## 基本流程

1. **说需求**：在工作台最下面的指令区写一句话，比如「海边的少女，夕阳，逆光」，按 Ctrl+Enter 或点「发送」。
2. **看过程**：日志抽屉从指令区向上展开，一行一条显示模型查了哪些标签。点遮罩可以收起，这一轮照常跑；需要停下点「中止」。
3. **检查回填**：成功后抽屉自动收起，结果填进提示词编辑器、负面词、参数区和角色区。看一眼，改几处。失败或中止时编辑器内容不动。
4. **出图**：点参数区最上面的「生成」（左边填跑图次数）。出图弹窗里一张张出现。
5. **想接着改**：打开指令区的「在现有内容上修改」再发一句，模型会在当前内容基础上改，而不是从头写。

每次发送都是全新一轮，不会记住上一次说过什么。

## 功能说明

### 顶栏

四个标签：**工作台**（写提示词、出图）、**画风维护**（管理画风预设）、**魔法书**（翻查标签分类与中文说明）、**设置**。

工作台左边是历史竖栏，中间是提示词编辑器、参数区与角色区，最下面固定着 LLM 指令区，右边是可以整体收起的 WIKI 竖栏。

### 提示词编辑器

十个字段常驻，空的也占位：

| 字段 | 放什么 |
|---|---|
| `count` | 人数、构图、镜头 |
| `style` | 画风标签 |
| `character` | 角色名 |
| `artist` | 画师名 |
| `appearance` | 发型、发色、瞳色、体型、服装、饰品 |
| `tags` | 动作、姿势、表情 |
| `environment` | 环境、背景、光影 |
| `series` | 作品名 |
| `nltags` | 自然语言补充 |
| `quality` | 质量词 |

- 退格到段首是跳到上一段末尾，不会把两段并成一段；空段拼接时整段跳过，不会留下多余逗号。
- 标签类字段里的全角逗号会标红；`nltags` 写中文句子，不标。
- 从别处粘贴的整段提示词落在当前段，不会自动拆到各字段。
- `Ctrl + ↑/↓` 调整光标所在标签的权重，步进 0.05。
- 「画面文字（text）」写要画进画面里的文字，出图时接到提示词末尾；留空则补 `no text`。
- 补全下拉每行带中文释义；输入中文时，末尾补上释义里包含这个词的标签（标「释义」）。

### 指令区选项

| 选项 | 作用 |
|---|---|
| 多角色 | 关闭 / 位置由模型安排 / 手动指定坐标。开启后模型会把各角色分别写进角色区 |
| 在现有内容上修改 | 把编辑器、负面词、参数、角色的当前内容一起发给模型，让它在此基础上改 |
| 透明背景 | 回填时强制打开参数区的「透明背景」 |
| 画风 | 不覆盖 / 用预设画风覆盖 / 用当前 artist 块覆盖（见下） |
| 回填后自动生成 | 回填成功后直接开始出图 |

**画风**决定模型返回的 `artist` 字段怎么处理：

| | |
|---|---|
| 不覆盖 | 用模型写的 |
| 用预设画风覆盖 | 丢弃模型写的，换成当前预设画风 |
| 用当前 artist 块覆盖 | 丢弃模型写的，保留编辑器里 `artist` 段现有内容 |

画风不会发给模型，后两档是回填前直接替换。指令区只显示当前预设名，点「选择预设…」去画风维护里换。

### 画风维护

- 左边是画风列表，按住拖动调整顺序；当前预设画风带绿点，并在列表最上面单独置顶，点它直接打开。
- 右边编辑名称和标签，改动即保存；双击名称或双击列表里的一行，名称框全选，直接打字就能改名。
- **选为预设画风**：设为当前预设（不会改指令区的画风档位）。
- **覆盖画风**：把这条画风整段写进工作台的 `artist` 块，并切回工作台。
- **从工作台提取**：把工作台 `artist` 块现在的内容存成一条新画风。
- **规范化权重与 @**：把 `{x}` `[x]` `(x:1.2)` 这类老写法转成 NAI 的 `1.05::x::`，`@xxx` 换成 `artist:xxx`，webui 转义的 `\(` `\)` 还原成普通括号。

### 参数区与出图

- 最上面是跑图次数和「生成」按钮，跑图中换成「取消」。
- 尺寸框里的宽高会在 LLM 回填时按宽高比与像素上限重算；总像素超过 1024×1024 时标题行红字提示超出 Opus 免费范围。
- Seed 模式选「固定」时 seed 框变黄；模型不会改 seed。
- 出图弹窗右侧常驻溯源信息（「本工具参数」/「图片元信息」）；单击切换看哪张，双击看原图，点遮罩或 × 关闭弹窗（不中断任务）。
- 「复制信息」把那张图的整套参数写回参数区，seed 取图片里的并改成固定——想重出同一张图就用它。
- 遇到 429（同一账号在别处出图）会暂停等你处理；Token 失效或点数不足直接中止整批，弹框里可一键打开设置。

### 历史

左侧历史竖栏列出最近几天（「历史保留天数」，默认 30）的每一轮，正在跑的那一轮排最前面实时走进度；点一条重新打开那一轮的出图弹窗，查看每张图当时的参数和真正发给 NovelAI 的提示词。

### 右侧 WIKI

工具栏最右端的「WIKI」按钮展开或整体收起右侧竖栏；收起时跟随光标等功能全部暂停。

- 顶部「画师 / 标签」切换数据源。「跟随光标」开着时，光标停在正向提示词的词上 0.4 秒后自动查询。
- 搜索框：标签用本地标签库联想（支持中文别名）；画师额外用 Danbooru 按别名、主页链接检索。
- 「+ 加入」把这个词插回上次光标所在的位置（画师自动加 `artist:`，下划线换成空格）。
- wiki 正文里的内链在栏内跳转，外链用系统浏览器打开；例图点开看原图。
- 标签词条下面显示中文说明卡片（释义、易误读、辨析）；搜索框输入中文时，联想末尾补上释义里包含这个词的标签（标「释义」）。

### 魔法书

顶栏「魔法书」把 LLM 的 browse_tags 工具用的那份分类数据摊开给人翻：9 组、126 类、1.7 万个标签，每个都带中文释义。

- 左边是分类树，点一类在中间列出这一类的全部标签（按帖子数排序）；标「易误读」的是字面意思容易理解错的，标「辨析」的有容易混淆的相近标签。
- 右边是选中标签的中文说明（释义、易误读提示、辨析）和 D 站 WIKI；辨析和 wiki 正文里的标签点了直接跳过去。
- 检索框能搜标签名、中文释义和中英日别名，几个词用空格隔开表示同时命中；左边的树只留有命中的分类。
- 「复制」把标签复制到剪贴板（下划线换成空格），再粘进提示词。

## 数据存在哪

- 设置、画风预设、工作状态：`%APPDATA%\llm-nai-toolbox\`。API Key、NovelAI Token 等密钥单独加密存放，绑定当前 Windows 用户——换电脑或换用户后需要重新填写。
- 出的图：设置里的保存目录下，按日期分子目录。

## 常见问题

| 现象 | 处理 |
|---|---|
| 发送后提示「还没有填写 API Key」 | 去「设置 → LLM API」填 Key 并保存 |
| 提示 API Key 无效或已过期（401 / 403） | Key 填错或过期，重新填写 |
| LLM 请求 404 | 多半是 API 地址多写了 `/v1`，去掉 |
| 模型不查标签、不回填 | 换一个支持工具调用的模型 |
| 点「生成」提示未配置 Token / 未设置保存目录 | 去「设置 → NovelAI」补上 |
| 出图暂停，提示 429 | 同一 NovelAI 账号在别处出图，等那边结束后点「继续」 |
| 访问不了接口或例图加载不出来 | 检查「设置 → 网络」的代理 |
