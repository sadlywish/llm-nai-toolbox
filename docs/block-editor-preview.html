随之确定的行为

  • 光标落在哪一块，输入就归哪一块——该块提亮，顶栏写出当前字段名，归属永远看得见。
  • 块边界删不穿：退格到块首跳到上一块末尾，不会把两块并成一块；空块也删不掉，只会跳过去。
  • 每块单独计 token，顶栏给合计与 1471 上限；超限在点生成之前就拦下，并指出最长的那块。
  • 全角逗号只在 TAG 类块标红（上图 tags 里那个），nltags 块是自然语言，不标。
  • 从别处粘进来的整段提示词落在当前块，不自动拆分；要拆另点「交给 LLM 拆分到各块」。
  • 补全走本地标签库：光标在 artist: 前缀词内只搜画师，在 character 块优先角色类，其余走通用类。
  • 拼接发给 NAI 时空块整段跳过，不会留下多余的逗号——屏幕上占位，输出里不占位。
